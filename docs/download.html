Overview & Settings Files

File Structure

LesserEvil.exe
The main desktop application.
LesserEvil/
Optional Windower companion addon. Required for some features.
maps/
Zone map image files used by the MAP tab.
config/
Persisted user settings, reference data, and runtime caches. Files in this folder are auto-created on first launch as needed; see breakdown below.

User Settings Files

App-wide and per-character configuration files.

global.json
App-wide settings: display & behavior toggles, transparency, zone delay, language, FFXI install path override, and the Warp Guard toggle + whitelist.
player.settings.json
Per-character settings - speed enable/amount, Smart Speed config, visibility flags, etc.
profiles.json
Saved profiles for all characters.
hotkeys.json
Hotkey definitions and their bound action sequences.
warpgroup.json
Per-character opt-in list for "Warp All" operations.
saved.points.json
Saved warp points.
entity_notes.json
User notes attached to specific entities in the SCAN tab.
