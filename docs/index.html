A tool for making FFXI playable in 2026!

All the great features of Project-Tako with additional QOL features for multiboxers: warp-all, profiles, entity scanning and tracking, updated maps, and more!

Getting started

  1. Download the latest release of LesserEvil from Github. Extract it to anywhere on your PC.
  2. Install Windower and copy the LesserEvil addon folder into your addons directory if you plan to use the extra features.
  3. Launch FFXI through Windower.
  4. Open the app. Your character(s) appear in the CHARACTER dropdown at the top.

Requirements

  • Windows 10 / 11.
  • FFXI installed (any region).
  • [OPTIONAL] Windower 4 LesserEvil addon loaded.
  • .NET Framework 4.6.1 runtime (preinstalled on most systems).
