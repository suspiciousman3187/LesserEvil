About

LesserEvil is a tool for Final Fantasy XI based on the early Project-Tako with some additional updates, reworked UI layout, and QOL features for multiboxers.

Background

Let's face it, Final Fantasy XI is a pretty bad game in 2026. It's an oldschool MMO, which means the name of the game is disrespecting your time. Some parts of the game some do this very cleverly, making us forget about it by masking it with fun content, some do it not so gracefully, and some do it so aggressively it becomes glaringly obvious at what it's doing.

We aren't in 2003 anymore. Most people today just don't have as much time as they did back then. Most adults will agree that time is the most valuable thing a person has, so with that in mind, I created LesserEvil.

What is LesserEvil?

LesserEvil is essentially a quality of life tool at heart. The goal is to give players the freedom to cut down on the more monotonous time-consuming tasks that the game has no shortage of.

Is it safe?

I don't know. Maybe not.

How is it different from Tako?

As a multiboxer, I noticed that while Project-Tako was excellent in its core functionality, it was a bit lacking for players who had to juggle multiple characters at once. Adjusting speed or warping for 1 character is fine, but what about 6 characters? At the end of the day, I wanted to see if I could cut down the sheer amount of clicking that was required to use Tako's original functions.

LesserEvil has some features which increase the quality of life for multiboxers such as profiles that automatically configure settings for multiple characters on zone change, and the Warp All feature which allows warping an entire party with a single button.

On top of that, I've added some extra features such as updating the map function for more recent content such as Sortie and Odyssey, as well as integrating it more closely with the rest of the app's features.

There are several other new features available, so if you would like a more detailed look, feel free to check out the Features section.
